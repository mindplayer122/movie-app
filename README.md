# 🎬 Movie App

A React movie application that displays popular movies using the **TMDB API**.

## ✨ Features

- 🎥 Displays popular movies from TMDB
- 🖼️ Movie posters
- 📝 Movie titles and overviews
- 📅 Release dates
- ⚠️ Displays fallback messages when movie information is unavailable
- 📱 Two-column movie grid

## 🛠️ Technologies Used

- React
- JavaScript
- Vite
- Tailwind CSS
- TMDB API
